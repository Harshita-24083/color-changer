Background Color Changer 🎨

A simple and interactive web project built using HTML, CSS, and JavaScript.

Features

- Change the webpage's background color by clicking a button.
- Display the current RGB color value.
- Simple and user-friendly interface.

Technologies Used

- HTML
- CSS
- JavaScript

How to Use

1. Open the project in your browser.
2. Click the Click Here button.
3. Watch the background color change and see the updated RGB value.
